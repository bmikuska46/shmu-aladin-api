SHMU ALADIN API

JSON API nad dátami numerického modelu ALADIN. Vyhľadávanie staníc a hodinové predpovede na nasledujúce 3 dni.

Rýchly štart

Služba sťahuje dáta zo SHMÚ a sprístupňuje ich cez HTTP. Základná adresa API:

Base URL
__WEB_URL__
StaniceViac ako 1 000 lokalít. Vyhľadávanie funguje aj bez diakritiky.
PredpoveďHodinové kroky na nasledujúce 3 dni (horizont modelu ALADIN): teplota, vietor, oblačnosť, zrážky a tlak.
Tip: Vyhľadávanie je bez diakritiky — zilina nájde aj „Žilina“.

Endpointy

Všetky endpointy používajú metódu GET. Chybové odpovede majú tvar {"code": 400, "message": "…"}.

GET/api/v1/stations

Zoznam staníc so stránkovaním a vyhľadávaním.

ParameterPopis
q, searchTextový filter, podporuje vyhľadávanie bez diakritiky.
pageČíslo stránky. Predvolená hodnota je 1.
page_size, limitVeľkosť stránky. Predvolená hodnota je 50, maximum 200.
GET/api/v1/stations/{id}
Detail stanice podľa ID. Napríklad 32737 označuje Bratislavu centrum.
GET/api/v1/forecast?station={id}

Najnovšia predpoveď ALADIN na nasledujúce 3 dni. Voliteľný parameter cnt určuje počet hodinových krokov.

Alias: /api/v1/weather?station={id}

Príklady použitia

Všetky príklady používajú vyššie uvedenú základnú adresu.

Vyhľadanie staníc

curl
curl "__WEB_URL__/api/v1/stations?q=zilina&page_size=5"

PowerShell

PowerShell
Invoke-RestMethod "__WEB_URL__/api/v1/stations?q=bratislava&page_size=3" |
  ConvertTo-Json -Depth 5

Predpoveď pre Bratislavu

curl · prvých 6 hodín
curl "__WEB_URL__/api/v1/forecast?station=32737&cnt=6"

Limity a aktualizácie

Obmedzenie požiadaviek

Predvolený limit je 10 požiadaviek za minútu pre každý endpoint a IP adresu. Pri prekročení API vráti stav 429 a hlavičku Retry-After. Dokumentácia nie je limitovaná.
