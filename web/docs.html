SHMU ALADIN API

JSON API nad dátami numerického modelu ALADIN. Vyhľadávanie staníc a hodinové predpovede na nasledujúce 3 dni.

Rýchly štart

Služba sťahuje dáta zo SHMÚ a sprístupňuje ich cez HTTP. Základná adresa API:

Base URL
__WEB_URL__/api/v1
StaniceViac ako 1 000 lokalít. Vyhľadávanie funguje aj bez diakritiky.
PredpoveďHodinové kroky na nasledujúce 3 dni (horizont modelu ALADIN): teplota, vietor, oblačnosť, zrážky a tlak.
Tip: Vyhľadávanie je bez diakritiky — zilina nájde aj „Žilina“.

Endpointy

Všetky endpointy používajú metódu GET. Chybové odpovede majú tvar {"code": 400, "message": "…"}.

Zoznam dostupných endpointov API (JSON).

GET/api/v1/forecast

Najnovšia predpoveď ALADIN na nasledujúce 3 dni. Zadajte buď station (ID stanice), alebo lat a lon (najbližšia stanica). Voliteľný parameter cnt určuje počet hodinových krokov.

Pri súradniciach odpoveď obsahuje location_match (vzdialenosť a nadmorská výška stanice). Voliteľne max_distance_km (max. 500) odmietne príliš vzdialenú zhodu.

Alias: /api/v1/weather s rovnakými parametrami.

ParameterPopis
stationID stanice. Alternatíva k lat + lon.
latZemepisná šírka (−90 až 90). Použite spolu s lon.
lonZemepisná dĺžka (−180 až 180). Použite spolu s lat.
cntPočet hodinových krokov v odpovedi.
max_distance_kmMaximálna vzdialenosť k najbližšej stanici (iba s lat/lon).
curl
curl "__WEB_URL__/api/v1/forecast?station=32737&cnt=6"
PowerShell
Invoke-RestMethod "__WEB_URL__/api/v1/forecast?station=32737&cnt=6" |
  ConvertTo-Json -Depth 6

GET/api/v1/indicators

Indikátory odvodené z hodinovej predpovede (mráz, horúčava, vietor, intenzívny dážď, sneh, zmiešané zrážky, nízka oblačnosť v horách). Nie sú oficiálnymi výstrahami SHMÚ — každá položka má official: false a source_kind: "forecast".

ParameterPopis
station / lat+lonRovnaké pravidlá ako pri predpovedi.
typeFiltrovanie typov oddelených čiarkou, napr. frost,wind,heavy_rain.
curl
curl "__WEB_URL__/api/v1/indicators?lat=49.12&lon=20.06&type=frost,wind"
PowerShell
Invoke-RestMethod "__WEB_URL__/api/v1/indicators?lat=49.12&lon=20.06&type=frost,wind" |
  ConvertTo-Json -Depth 6

{

Limity a aktualizácie

Obmedzenie požiadaviek

Predvolený limit je 10 požiadaviek za minútu pre každý endpoint a IP adresu. Pri prekročení API vráti stav 429 a hlavičku Retry-After. Dokumentácia nie je limitovaná.
